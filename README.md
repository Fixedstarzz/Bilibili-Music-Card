# Bilibili 音乐卡片

> 当前版本：v1.0.0

把任意 B 站视频链接变成歌单。一个单文件油猴脚本（约 76 KB，零外部依赖），在网页上悬浮一张
半透明的音乐卡片，后台播放 B 站视频的音频流。

## 功能

- **悬浮卡片**：封面模糊背景（0 = 清晰 → 40 = 重度，带档位小圆点实时反馈）、
  播放/暂停、上一首/下一首、进度拖动（流式加载，即拖即响）、音量（弹出滑杆 + 档位反馈）
- **三种播放模式**：顺序 / 随机 / 单曲循环；顺序播放完整个列表后自动停止
- **播放列表管理**：面板直接显示视频标题，↑/↓ 微调、拖拽排序、✕ 移除；
  放大按钮弹出居中大窗完整整理列表；「清空」一键移除全部（二次确认防误触）
- **后台播放**：多标签「引擎/遥控」架构——引擎驻留一个标签页持续出声，
  其他标签页上的卡片都是实时遥控器；引擎关闭后自动接管续播
  （默认仅在 B 站相关页面运行，其他页面可从油猴菜单临时启用）
- **扫码登录 B 站**：面板内置二维码（零依赖本地生成），登录后取流走账号通道：
  更高音频码率、解锁仅登录可见视频；凭证本地缓存 + 过期自动检测
- **B 站页快捷添加**：视频页一键加入当前视频；收藏夹页自动遍历整夹导入（上限 200 条）
- **仅B站运行**：默认只在 B 站相关页面（直播页除外）启动，无关网页零占用
- **深色/浅色主题**：自动跟随系统外观，无切换按钮
- **网页全屏避让**：B 站「网页全屏」时组件自动隐藏，退出后恢复
- **系统媒体控制（MediaSession）**：键盘媒体键、蓝牙耳机按钮、系统媒体浮层直接控制播放/切歌，
  锁屏与系统 UI 显示封面和曲名
- **下一曲预加载**：当前曲播放过 70% 时自动预取下一首直链，切歌零等待
- **卡顿缓冲保护**：播放因网络卡住超 4 秒自动暂停缓冲并提示，缓冲足够后自动续播
- **当前播放行高亮**：面板与放大列表中粉色标出正在播放的曲目，随切歌实时移动
- **单曲续播记忆**：每首视频记住播放位置（超过 30 秒才记录，听完整首则清除），再次播放自动续播
- **全量状态持久化**：播放列表、登录凭证、播放进度、音量、模式、模糊度、卡片位置，
  全部保存在本地（Tampermonkey 脚本存储），重启浏览器不丢

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 下载或直接点击 [bilibili-music-card.user.js](bilibili-music-card.user.js)
   （GitHub 页面也可用 raw 链接：`https://raw.githubusercontent.com/<你的用户名>/<仓库名>/main/bilibili-music-card.user.js`）
3. 油猴弹出安装页，点「安装」；从 GitHub raw 链接安装的脚本会自动跟踪仓库更新

> 首次调用 B 站接口时 Tampermonkey 可能询问跨域权限（`api.bilibili.com`、
> `passport.bilibili.com` 等），选择「总是允许」。

## 使用

| 操作 | 方式 |
|---|---|
| 添加歌曲 | 面板顶部单行输入框：粘贴后回车即加入并自动清空；空格分隔可批量；支持 BV / av / b23.tv 短链 / `?p=n` 分P |
| 播放 / 暂停 | ▶ 按钮，或直接点封面 |
| 上一首 / 下一首 | ⏮ ⏭ 按钮 |
| 顺序 / 随机 / 单曲循环 | 模式按钮三态切换（非顺序模式图标变粉） |
| 顺序播放完自动停止 | 默认策略：播至列表末尾自动停止并提示，随机/单曲循环不受影响 |
| 进度拖动 | 进度条（流式加载，即拖即响） |
| 音量 | 点/hover 喇叭图标弹出滑杆；滑动时显示拇指小球与实时档位 |
| 背景模糊度 | 面板「背景模糊」滑杆（0 = 清晰封面，40 = 重度模糊），同样带档位反馈；模糊同时作用于卡片、设置面板与放大列表 |
| 卡片不透明度 | 面板「不透明度」滑杆（30%–100%），同步作用于卡片、设置面板与放大列表，深色页面上可调浓以保证可读性 |
| 快捷添加 | 在 B 站视频页可「添加当前视频」；收藏夹页可「遍历添加整个收藏夹」 |
| 列表管理 | 面板列表显示视频标题：↑/↓ 调序、拖拽排序、✕ 移除 |
| 搜索过滤 | 放大窗顶部输入关键字实时过滤列表，标题计数显示匹配进度 |
| 批量管理 | 放大窗「管理」→ 点击行多选 → 移除/置顶/置底；全选/反选作用于搜索结果；排序按钮循环四种方式；「撤销」回退 |
| 放大列表 | 面板头部放大按钮弹出居中大窗；默认随面板关闭，图钉钉住后保持打开；含「清空」 |
| 移动卡片 | 按住卡片拖动（位置自动记忆） |
| 迷你模式 | 双击卡片缩成一张小封面并自动滑向最近的屏幕边缘，再双击或点封面还原（全尺寸位置不变）；缩小同时自动收起设置面板 |
| 打开面板 | 卡片齿轮按钮，或 Tampermonkey 菜单「打开播放列表 / 设置」 |
| 打开原视频 | 点击卡片标题，新标签页打开对应的 B 站视频页 |
| 卡顿处理 | 网络较慢播放卡住超过 4 秒时，自动暂停缓冲并提示，缓冲足够后自动续播 |
| 主题 | 深色/浅色自动跟随系统外观 |
| 运行范围 | 默认策略：仅在 B 站相关页面运行（直播页除外），其他网页不启动；油猴菜单保留「在此页面运行（临时）」逃生口 |
| 网页全屏 | B 站「网页全屏」时组件自动隐藏，退出后恢复 |
| 直播页 | 打开 B 站直播（live.bilibili.com）时组件自动隐藏 |
| 视频避让 | 当前网页有视频正在播放时自动暂停本插件（每轮视频播放只打断一次，手动恢复后不再打扰） |

## 扫码登录 B 站

- 面板顶部内置登录区：打开面板即显示二维码，状态实时更新
  （等待扫码 → 已扫码，请在手机上点击确认 → 登录成功）
- 二维码约 3 分钟过期，会自动刷新
- 登录后显示头像 + 昵称，可随时「退出登录」；点「暂不登录」可折叠为精简条
- **凭证本地缓存与过期检测**：凭证保存在本地，启动时优先使用本地 key 静默校验（10 分钟节流）；
  校验失效自动清除并回到扫码界面，取流失败也会自动退回匿名通道，不影响基础播放
- 登录后取流自动携带账号凭证（`SESSDATA`）：更高音频码率、解锁仅登录可见视频、降低风控概率
- 也可以从 Tampermonkey 菜单点「扫码登录 B 站」直接唤出

## 安全与隐私

- **出站流量**：仅请求 B 站官方接口域（`api.bilibili.com` / `passport.bilibili.com` / `passport.biligame.com` / `b23.tv`）；音频与封面资源走 `*.bilivideo.com` / `*.bilivideo.cn` / `*.hdslb.com` CDN。无任何第三方统计、字体、CDN 或遥测
- **域名白名单**：对 API 返回的封面、音频流、登录回调做强制域校验——不符即回退占位图、拒绝取流或不发请求
- **凭据存储**：`SESSDATA` 等登录凭证只存在于 Tampermonkey 的脚本本地存储，不进入页面 DOM、不打印到控制台，仅在请求 `api.bilibili.com` 时附加；其敏感级别与浏览器 Cookie 中的登录态等同
- **接口隔离**：卡片 UI 位于 closed Shadow DOM，被访问的网页无法读取卡片内部，更无法触及脚本存储
- **权限最小化**：不申请 `unsafeWindow`、不使用 `eval`、不读取页面 Cookie；跨域请求被 `@connect` 限定在上述 B 站官方域名内
- 扫码登录的二维码与凭据仅在本机浏览器与 B 站官方接口之间流转，不经过任何第三方服务

## 已知限制

- **同一标签页内跳转**后浏览器可能拦截自动续播，点一下播放键即可（新标签页遥控不受影响）
- 个别站点严格的 CSP（如 `media-src 'none'`）可能阻止音频播放，属浏览器安全策略，脚本无法绕过
- 付费/充电专属视频需要对应权益才能取流，无权限时会提示后自动跳过
- 未登录音频码率有限；扫码登录后自动走账号通道
- 背景模糊的感知强度取决于背后页面的内容密度——空白页上几乎不可见，属 backdrop-filter 的物理特性
